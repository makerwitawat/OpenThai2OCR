OpenThai2.0 OCR คู่มือเชื่อมต่อ API

OCR สอนใช้ API ทดสอบ API สถานะ ตั้งค่า
v{{ version }}

ใช้ API เดียวกันกับหน้าเว็บ — เรียกจากโปรแกรมอื่น ระบบอื่น หรือภาษาสคริปต์ใด ๆ ได้ทันที (HTTP + JSON) ไม่ต้องติดตั้ง SDK

ที่อยู่เริ่มต้น: http://127.0.0.1:5000

API key (ถ้าเปิดโหมด LAN): ส่งผ่าน header X-API-Key หรือ query ?key= — หน้าเว็บเก็บ key ไว้ใน localStorage ของเบราว์เซอร์

1. เริ่มต้นเร็ว

ตรวจว่าระบบพร้อมใช้ก่อนเสมอ (ไม่ต้องใช้ key)

curl -s http://127.0.0.1:5000/api/health

อ่านภาพหนึ่งไฟล์แล้วได้ข้อความ + พิกัดบรรทัด + ความมั่นใจ

curl -s -X POST http://127.0.0.1:5000/api/ocr -F "file=@invoice.jpg"

2. รายการ endpoint

เส้นทางใช้ทำอะไร
GET/api/health สถานะเครื่อง/โมเดล/version/watch folder
GET/api/status สถานะละเอียด + งาน OCR ล่าสุด 20 งาน + uptime
POST/api/ocr อ่านรูป/PDF (multipart file หรือ JSON base64)
POST/api/jobs เริ่มงานเบื้องหลัง (PDF หลายหน้า) แล้วถามความคืบหน้าได้
GET/api/jobs/<id> ความคืบหน้า/ผลลัพธ์ของงาน
POST/api/jobs/<id>/cancel ยกเลิกงาน
GETPOST/api/result/<id>/export ส่งออกผลลัพธ์: format=pdf|csv|json|txt|docx · POST พร้อม JSON {"text":"..."} = ส่งออกด้วยข้อความที่แก้แล้ว
GET/api/update-check ตรวจเวอร์ชันใหม่จาก GitHub (cache 6 ชม. · ปิดได้ด้วย prefs update_check)
GETPOST/api/prefs อ่าน/บันทึกค่าตั้งเช่น open_browser
POST/api/shutdown ปิดโปรแกรม (เรียกได้จากเครื่องเดียวกันเท่านั้น)

ฟิลด์ความหมาย
pages[].textข้อความของหน้านั้น
pages[].lines[]แต่ละบรรทัด: ข้อความ, ความมั่นใจ, พิกัดสี่มุม, คำย่อย
pages[].scaleอัตราขยายภาพที่ใช้จริง (พิกัดอ้างอิงภาพหลังขยาย)
pages[].size[กว้าง, สูง] ของภาพที่ประมวลผล — ใช้เป็น viewBox เมื่อวาดกรอบทับภาพ
result_idใช้เรียก export ได้ (เก็บผลไว้ 5 ล่าสุด)

5. ตัวเลือกตอนเรียก

พารามิเตอร์ค่า
fileไฟล์ภาพ/PDF (multipart) — สูงสุด {{ max_upload_mb }} MB, PDF {{ max_pages }} หน้า
image_base64ส่งเป็น JSON แทนไฟล์ได้ (รองรับ data:URL)
scaleauto (แนะนำ) · 1 · 1.5 · 2
images0 = ไม่ส่งภาพผลลัพธ์กลับ (เร็ว/ประหยัดแบนด์วิดท์)
overlay0 = ภาพผลลัพธ์เป็นภาพเปล่า ไม่ฝังกรอบ (วาดเองจาก lines[].box + size)
settingsJSON ปรับละเอียด เช่น {"rec":{"drop_below":0.85}}

settings ที่ใช้บ่อย

คีย์ขอบเขตผล
rec.drop_below0–1ตัดบรรทัดที่ความมั่นใจต่ำกว่า (เช่น 0.85)
rec.min_chars0–50ตัดบรรทัดสั้นเกิน
rec.junk_below / rec.junk_invalid0–1ตัดของรก/ตัวสะกดเสีย
det.split_gap0–4แยกบรรทัดที่ติดกัน (สัดส่วนความสูงบรรทัด)
det.limitจำนวนบรรทัดสูงสุดจำกัดจำนวนบรรทัดต่อหน้า
rec.batch1–64จำนวนบรรทัดต่อรอบประมวลผล (เร็วขึ้นถ้า CPU ไหว)
ค่าเริ่มต้นปรับได้ในไฟล์ models/config.json — ส่ง settings มาเฉพาะค่าที่อยากเปลี่ยน

6. งานเบื้องหลัง (PDF หลายหน้า)

สร้างงาน → ถามความคืบหน้าจนสถานะเป็น done → อ่านผลลัพธ์ (หรือยกเลิก)

curl -s http://127.0.0.1:5000/api/jobs/ab12cd34

#     "result_id":"ab12cd34","text":"...","pages":[...]}

curl -s -X POST http://127.0.0.1:5000/api/jobs/ab12cd34/cancel

7. ข้อผิดพลาดและขีดจำกัด

HTTPความหมาย
400ไฟล์ว่าง/นามสกุลไม่รองรับ/PDF เกินหน้า
401เปิด LAN mode แล้วไม่ส่ง API key หรือ key ผิด
404ไม่พบผลลัพธ์/งาน (หมดอายุ)
413ไฟล์ใหญ่เกิน {{ max_upload_mb }} MB
500อ่านไฟล์ไม่สำเร็จ (ดูรายละเอียดใน logs)

8. เฝ้าโฟลเดอร์ (ไม่ต้องเขียนโค้ด)

python app.py --watch "D:\inbox" --watch-out "D:\outbox" --watch-interval 5
OpenThai2OCR.exe --watch "D:\inbox" --watch-out "D:\outbox" --no-browser

ไฟล์ใหม่ใน D:\inbox จะถูกอ่านแล้วเขียน ชื่อ-ocr.txt, ชื่อ-ocr.docx, ชื่อ-ocr.json ลง D:\outbox (ต้นฉบับไม่ถูกย้าย)
