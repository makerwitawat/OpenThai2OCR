# คู่มือการใช้งาน — OpenThai2.0 OCR

## 1. เปิดโปรแกรม

| แบบ | วิธี |
|---|---|
| exe (Windows) | ดับเบิลคลิก `OpenThai2OCR.exe` แล้วรอเบราว์เซอร์เปิดเอง |
| รันจากซอร์ส | `python app.py` (ต้อง `pip install -r requirements.txt` ก่อน) |
| ไม่เปิดเบราว์เซอร์อัตโนมัติ | เพิ่ม `--no-browser` ต่อท้าย |
| เปลี่ยนพอร์ต | `--port 8080` |
| ให้เครื่องอื่นใน LAN เรียก | `--host 0.0.0.0` (เปิดไฟร์วอลล์ให้พอร์ตนั้นด้วย) |
| ชี้โฟลเดอร์โมเดลอื่น | `--model "D:\path\models"` |

> ครั้งแรกของ exe ไฟล์เดียวจะช้าหลายวินาที เพราะต้องแตกไฟล์ภายในไปที่โฟลเดอร์ชั่วคราว (ปกติ)

## 2. ใส่วภาพเข้าโปรแกรม

ทำได้ 4 ทาง

1. **ลากไฟล์** มาวางในกรอบเส้นประ
2. **คลิกกรอบ** แล้วเลือกไฟล์ (เลือกหลายไฟล์พร้อมกันได้)
3. **Ctrl + V** — คัดลอกภาพหน้าจอจาก Snipaste / Print Screen / Snipping Tool แล้ววางในหน้าเว็บ
4. **API** — ส่งจากโปรแกรมอื่น (ดู [API.md](API.md))

รับนามสกุล: PNG, JPG/JPEG, BMP, TIF/TIFF, WEBP, PDF (ทุกหน้า)

## 3. อ่านผลลัพธ์

- ระบบเริ่ม OCR ให้อัตโนมัติทันทีที่ไฟล์เข้ามา
- ฝั่งซ้าย = ภาพที่วาดกรอบบรรทัด + ค่าความมั่นใจ (มุมซ้ายบนของแต่ละกรอบ)
- ฝั่งขวา = ข้อความตามลำดับการอ่าน (รองรับ 2–3 คอลัมน์)
- มีหลายไฟล์/หลายหน้า → แท็บด้านล่างภาพ
- ปุ่ม **คัดลอก** / **ดาวน์โหลด .txt**

## 4. ปรับความแม่นยำ

### 4.1 ความละเอียดภาพ (ในหน้าเว็บ)

ตัวเลือก "ความละเอียดภาพ" เหนือปุ่มประมวลผล

| ค่า | ใช้เมื่อ |
|---|---|
| อัตโนมัติ | ภาพใหญ่ปกติ (ไม่ต้องยุ่ง) |
| 1× | ภาพความละเอียดสูงอยู่แล้ว ต้องการเร็วสุด |
| 1.5× | ตัวอักษรเล็ก ปานกลาง |
| 2× | ภาพหน้าจอเล็ก / ตัวอักษรจิ๋ว — แม่นขึ้นแต่ช้าลง |

### 4.2 ตั้งค่าผ่าน API (`settings`)

ส่ง JSON แนบไปกับ request เช่น

```json
{
  "image_base64": "...",
  "settings": {
    "det": {"limit": 1600, "v_pad": 0.15, "split_gap": 1.2},
    "rec": {"drop_below": 0.8, "min_chars": 2, "color": "flatten"}
  }
}
```

| ค่า | ความหมาย | ช่วงที่ปลอดภัย |
|---|---|---|
| `det.limit` | ขนาดยาวสุดที่ detector ย่อภาพไปประมวลผล | 320–4096 (สูง = แม่นขึ้น ช้าลง) |
| `det.v_pad` | ขยายความสูงกรอบบรรทัด (ช่วยวรรณยุกต์ไทยที่ถูกตัด) | 0–1 |
| `det.split_gap` | ตัดบรรทัดที่ถูก merge ข้ามคอลัมน์ ถ้าช่องว่าง ≥ กี่เท่าของความสูงบรรทัด | 0–4 (0 = ปิด) |
| `det.box_thresh` | ความมั่นใจขั้นต่ำของกรอบที่ยอมรับ | 0.1–0.99 |
| `rec.drop_below` | ตัดบรรทัดที่ความมั่นใจต่ำกว่านี้ (เช่นกล่องตราประทับ) | 0–1 |
| `rec.min_chars` | ตัดบรรทัดที่มีตัวอักษรน้อยกว่านี้ | 0–50 |
| `rec.junk_below` / `rec.junk_invalid` | ตัดบรรทัดที่ความมั่นใจต่ำและสะกดไทยเพี้ยนเกินสัดส่วน | 0–1 |
| `rec.color` | วิธีเตรียมภาพก่อนอ่าน: `flatten` (ค่าเริ่มต้น), `gray`, `gray_inv`, `stretch`, `bgr` | — |

> ค่าเหล่านี้ถูกจำกัดช่วงและตรวจชนิดอัตโนมัติ ค่าที่ไม่ถูกต้องจะถูกเมิน (ไม่ทำให้โปรแกรมพัง)
> ค่าเดียวกันนี้แก้ถาวรได้ใน `models/config.json`

### 4.3 เคล็ดลับจากอาการที่เจอบ่อย

| อาการ | ลอง |
|---|---|
| ตัวอักษรเล็ก/ภาพหน้าจอ อ่านผิดบางตัว | ความละเอียด 2× หรือ `det.limit` 1600–2000 |
| วรรณยุกต์ไทยหาย/เพี้ยน | `det.v_pad` 0.1–0.2 |
| บรรทัดสองคอลัมน์ถูกรวมเป็นบรรทัดเดียว | `det.split_gap` 1.0–1.5 |
| ข้อความสี/พื้นหลังเข้ม | `rec.color` = `flatten` (ค่าเริ่มต้น) หรือ `gray_inv` |
| อยากได้เฉพาะบรรทัดที่มั่นใจ | `rec.drop_below` 0.85–0.92 |
| อ่านช้า | ลด `det.limit` เป็น 960 หรือใช้ 1× |

## 5. ขนาดตัวอักษรของหน้าเว็บ

- ปุ่ม `A−` / `A` / `A+` มุมขวาบน — ปรับแล้วจำค่าไว้ครั้งหน้า
- ค่าเริ่มต้นสเกลตามความกว้างจออัตโนมัติ (จอใหญ่ตัวใหญ่ขึ้น)

## 6. ใช้งานผ่านโปรแกรมอื่น (API)

เปิดโปรแกรมค้างไว้ แล้วเรียก

```bash
curl -F "file=@page.png" "http://127.0.0.1:5000/api/ocr"
```

ดูตัวอย่าง PHP / Python / JavaScript / C# และรายละเอียดฟิลด์ → [API.md](API.md)

## 7. แก้ปัญหาที่พบบ่อย

| ปัญหา | สาเหตุ/วิธีแก้ |
|---|---|
| เปิด exe แล้วเบราว์เซอร์ไม่ขึ้น | เปิด `http://127.0.0.1:5000` เอง · ถ้าพอร์ตชน ให้รัน `--port 8080` |
| "Windows protected your PC" | ไฟล์ exe ไม่ได้เซ็นชื่อ — กด More info → Run anyway |
| ขึ้น "ไม่พบไฟล์โมเดล" | ใช้ build แบบ onedir ต้องมีโฟลเดอร์ `models` ข้าง exe (onefile ฝังในตัวแล้ว) |
| เครื่องอื่นเรียก API ไม่ได้ | รันด้วย `--host 0.0.0.0` + เปิด Firewall ขาเข้าพอร์ตนั้น |
| อ่านช้ามาก | ลดความละเอียด/`det.limit` · ปิดโปรแกรมอื่นที่กิน CPU |
| ลายมืออ่านไม่ขึ้น | โมเดลนี้ออกแบบสำหรับตัวพิมพ์ — ลายมือต้องใช้โมเดล VLM อื่น |
| ภาษาไทยเพี้ยนในโปรแกรมอื่น | ตรวจว่าโปรแกรมปลายทางอ่าน response เป็น UTF-8 |

## 8. โครงสร้างโปรเจกต์

```
app.py                  เซิร์ฟเวอร์ Flask + API + ตัวจัดการภาพ
templates/index.html    หน้าเว็บ (ธีมขาว, paste, หลายไฟล์, สเกลฟอนต์)
models/                 โมเดล ONNX + runtime (line_engine.py, thai_norm.py)
models/runtime/         ตัวอ่านหน้า (LineOCR) จาก Hugging Face
docs/                   คู่มือ, API, build
tools/                  สคริปต์ช่วยเหลือ (ดาวน์โหลดโมเดล, release notes)
build_exe.bat           build exe ไฟล์เดียว (Windows)
OpenThai2OCR.spec       สเปก PyInstaller แบบ onefile
```
