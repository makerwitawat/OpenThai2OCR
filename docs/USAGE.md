# คู่มือการใช้งาน — OpenThai2.0 OCR

**ไทย** | [English](USAGE.en.md)

## 1. เปิดโปรแกรม

| แบบ | วิธี |
|---|---|
| exe (Windows) | ดับเบิลคลิก `OpenThai2OCR.exe` แล้วรอเบราว์เซอร์เปิดเอง |
| รันจากซอร์ส | `python app.py` หรือ `run_web.bat` บน Windows (ต้อง `pip install -r requirements.txt` ก่อน) |
| ไม่เปิดเบราว์เซอร์อัตโนมัติ | เพิ่ม `--no-browser` ต่อท้าย |
| เปลี่ยนพอร์ต | `--port 8080` |
| ให้เครื่องอื่นใน LAN เรียก | `--host 0.0.0.0` (เปิดไฟร์วอลล์ให้พอร์ตนั้นด้วย) |
| ชี้โฟลเดอร์โมเดลอื่น | `--model "D:\path\models"` |

> ครั้งแรกของ exe ไฟล์เดียวจะช้าหลายวินาที เพราะต้องแตกไฟล์ภายในไปที่โฟลเดอร์ชั่วคราว (ปกติ)

## 2. ใส่วภาพเข้าโปรแกรม

ทำได้ 4 ทาง

1. **ลากไฟล์** มาวางในกรอบเส้นประ
2. **คลิกกรอบ** แล้วเลือกไฟล์ (เลือกหลายไฟล์พร้อมกันได้)
3. **Ctrl + V** — คัดลอกภาพหน้าจอจาก Snipaste / Print Screen / Snipping Tool แล้ววางในหน้าเว็บ
4. **API** — ส่งจากโปรแกรมอื่น (ดู [API.md](API.md))

รับนามสกุล: PNG, JPG/JPEG, BMP, TIF/TIFF, WEBP, PDF (ทุกหน้า)

### เฝ้าโฟลเดอร์อัตโนมัติ (watch folder)

ไม่ต้องลากไฟล์เอง — สั่งให้โปรแกรมเฝ้าโฟลเดอร์ แล้ววางไฟล์ลงไปได้เลย

```bash
python app.py --watch "D:\inbox"                          # ผลลัพธ์ -> D:\inbox\ocr-results
python app.py --watch "D:\inbox" --watch-out "D:\out"     # เลือกที่เก็บผลเอง
python app.py --watch "D:\inbox" --watch-interval 3       # ตรวจทุก 3 วินาที (ค่าเริ่มต้น 5)
```

- ผลลัพธ์ต่อไฟล์: `<ชื่อ>-ocr.txt`, `<ชื่อ>-ocr.docx`, `<ชื่อ>-ocr.json`
- ไฟล์ต้นฉบับ **ไม่ถูกย้าย/ลบ** · ไฟล์เดิมอ่านซ้ำเฉพาะเมื่อขนาด/เวลาแก้เปลี่ยน
- ไฟล์ที่ยังคัดลอกไม่เสร็จจะถูกข้ามไปก่อน (รอให้หยุดเขียน)

## 3. อ่านผลลัพธ์

- ระบบเริ่ม OCR ให้อัตโนมัติทันทีที่ไฟล์เข้ามา
- ฝั่งซ้าย = ภาพพร้อมกรอบสีเขียวทับบรรทัดที่อ่านได้ — **คลิกกรอบ** เพื่อเลือกบรรทัดนั้น
  (ข้อความที่ตรงกันจะถูกไฮไลต์ในช่องขวา) หรือคลิกในช่องข้อความ/รายการรายบรรทัดเพื่อให้กรอบบนภาพถูกเลือกตาม ·
  เอาเมาส์ชี้กรอบเพื่อดูค่าความมั่นใจ · คลิกพื้นที่นอกกรอบเพื่อดูภาพเต็มจอ
- ฝั่งขวา = ข้อความตามลำดับการอ่าน (รองรับ 2–3 คอลัมน์)
- มีหลายไฟล์/หลายหน้า → แท็บด้านล่างภาพ
- ปุ่ม **คัดลอก** / **.txt** / **.docx** / **.pdf** / **.csv** / **.json**
  - `.pdf` = PDF ที่ **ค้นหาข้อความได้** (มี text layer ซ่อนเหนือภาพ)
  - `.docx` = Word — บรรทัดละย่อหน้า แก้ไข/จัดรูปแบบต่อได้ทันที
  - `.csv` = บรรทัดพร้อมค่าความมั่นใจและพิกัดกรอบ (เปิด Excel ได้)
  - `.json` = ผลเต็มรูปแบบสำหรับนำไปใช้ต่อ
- **แก้ข้อความในช่องขวาได้เลย** — ปุ่ม `.txt` `.docx` `.pdf` `.csv` `.json` จะส่งออกด้วยข้อความที่แก้แล้ว
  (หลายไฟล์: ให้คงหัว `=== ชื่อไฟล์ ===` ไว้ · PDF/CSV ถ้าจำนวนบรรทัดเท่าเดิมจะวางตรงกรอบเดิม)
- **ตรวจอัปเดตอัตโนมัติ** — เมื่อเปิดหน้าเว็บ โปรแกรมถาม GitHub ว่ามีเวอร์ชันใหม่ไหม (ไม่ส่งไฟล์หรือข้อมูลใด ๆ)
  ถ้ามีจะขึ้นแถบแจ้งด้านบน ปิดได้ที่ช่อง "ตรวจอัปเดตอัตโนมัติ" ในแถบตัวเลือก
- ปุ่ม **รายบรรทัด** — กางรายการทุกบรรทัดของหน้าปัจจุบัน พร้อมค่าความมั่นใจ
  กด **คัดลอก** ทีละบรรทัด หรือ **คัดลอกทุกบรรทัด** ทั้งหน้า
- PDF หลายหน้า: มีแถบความคืบหน้า "หน้า x/y" และปุ่ม **ยกเลิก** ระหว่างอ่าน

## 4. ปรับความแม่นยำ

### 4.1 ความละเอียดภาพ (ในหน้าเว็บ)

ตัวเลือก "ความละเอียดภาพ" เหนือปุ่มประมวลผล

| ค่า | ใช้เมื่อ |
|---|---|
| อัตโนมัติ | ภาพใหญ่ปกติ (ไม่ต้องยุ่ง) |
| 1× | ภาพความละเอียดสูงอยู่แล้ว ต้องการเร็วสุด |
| 1.5× | ตัวอักษรเล็ก ปานกลาง |
| 2× | ภาพหน้าจอเล็ก / ตัวอักษรจิ๋ว — แม่นขึ้นแต่ช้าลง |

### 4.2 ตั้งค่าผ่าน API (`settings`)

ส่ง JSON แนบไปกับ request เช่น

```json
{
  "image_base64": "...",
  "settings": {
    "det": {"limit": 1600, "v_pad": 0.15, "split_gap": 1.2},
    "rec": {"drop_below": 0.8, "min_chars": 2, "color": "flatten"}
  }
}
```

| ค่า | ความหมาย | ช่วงที่ปลอดภัย |
|---|---|---|
| `det.limit` | ขนาดยาวสุดที่ detector ย่อภาพไปประมวลผล | 320–4096 (สูง = แม่นขึ้น ช้าลง) |
| `det.v_pad` | ขยายความสูงกรอบบรรทัด (ช่วยวรรณยุกต์ไทยที่ถูกตัด) | 0–1 |
| `det.split_gap` | ตัดบรรทัดที่ถูก merge ข้ามคอลัมน์ ถ้าช่องว่าง ≥ กี่เท่าของความสูงบรรทัด | 0–4 (0 = ปิด) |
| `det.box_thresh` | ความมั่นใจขั้นต่ำของกรอบที่ยอมรับ | 0.1–0.99 |
| `rec.drop_below` | ตัดบรรทัดที่ความมั่นใจต่ำกว่านี้ (เช่นกล่องตราประทับ) | 0–1 |
| `rec.min_chars` | ตัดบรรทัดที่มีตัวอักษรน้อยกว่านี้ | 0–50 |
| `rec.junk_below` / `rec.junk_invalid` | ตัดบรรทัดที่ความมั่นใจต่ำและสะกดไทยเพี้ยนเกินสัดส่วน | 0–1 |
| `rec.color` | วิธีเตรียมภาพก่อนอ่าน: `flatten` (ค่าเริ่มต้น), `gray`, `gray_inv`, `stretch`, `bgr` | — |

> ค่าเหล่านี้ถูกจำกัดช่วงและตรวจชนิดอัตโนมัติ ค่าที่ไม่ถูกต้องจะถูกเมิน (ไม่ทำให้โปรแกรมพัง)
> ค่าเดียวกันนี้แก้ถาวรได้ใน `models/config.json`

### 4.3 เคล็ดลับจากอาการที่เจอบ่อย

| อาการ | ลอง |
|---|---|
| ตัวอักษรเล็ก/ภาพหน้าจอ อ่านผิดบางตัว | ความละเอียด 2× หรือ `det.limit` 1600–2000 |
| วรรณยุกต์ไทยหาย/เพี้ยน | `det.v_pad` 0.1–0.2 |
| บรรทัดสองคอลัมน์ถูกรวมเป็นบรรทัดเดียว | `det.split_gap` 1.0–1.5 |
| ข้อความสี/พื้นหลังเข้ม | `rec.color` = `flatten` (ค่าเริ่มต้น) หรือ `gray_inv` |
| อยากได้เฉพาะบรรทัดที่มั่นใจ | `rec.drop_below` 0.85–0.92 |
| อ่านช้า | ลด `det.limit` เป็น 960 หรือใช้ 1× |

### 4.4 ขีดจำกัดของโปรแกรม

| รายการ | ค่าเริ่มต้น | หมายเหตุ |
|---|---|---|
| ขนาดไฟล์อัปโหลด | 100 MB | เกินแล้วได้ข้อความแจ้งเตือน |
| จำนวนหน้า PDF | 50 หน้า | เกินแล้วให้แบ่งไฟล์ |
| เก็บผลลัพธ์ล่าสุด | 5 รายการ | ใช้สำหรับปุ่ม export |
| พอร์ต | 5000–5010 | ถ้าชนจะเลื่อนอัตโนมัติ |
| ไฟล์ log | `logs/openthai-ocr.log` | หมุนเวียน 2MB × 3 ไฟล์ |

> โหมด LAN (`--host 0.0.0.0`) ถ้าไม่ระบุ `--api-key` โปรแกรมจะสร้าง key สุ่มให้และแสดงในหน้าต่างแจ้งเตือน
> หน้าเว็บจะถาม key ครั้งแรกแล้วจำไว้ (ส่ง header `X-API-Key`)

## 5. ขนาดตัวอักษรของหน้าเว็บ

- ปุ่ม `A−` / `A` / `A+` มุมขวาบน — ปรับแล้วจำค่าไว้ครั้งหน้า
- ค่าเริ่มต้นสเกลตามความกว้างจออัตโนมัติ (จอใหญ่ตัวใหญ่ขึ้น)
- ปุ่ม **EN / ไทย** สลับภาษาหน้าเว็บ (จำค่าไว้)
- ปุ่ม **ปิดโปรแกรม** มุมขวาบน (ปิดเซิร์ฟเวอร์ได้เลย ไม่ต้องใช้ Task Manager)
- เลข version แสดงมุมขวาบน

## 5.1 หน้าใหม่ในเว็บ

| หน้า | ใช้ทำอะไร |
|---|---|
| `/` | อ่าน OCR จากรูป/PDF (หน้าเดิม) |
| `/docs` | สอนเชื่อมต่อ API: endpoint ทั้งหมด, ตัวอย่างโค้ด curl / Python / JS / PHP / C#, `settings` ที่ใช้บ่อย |
| `/playground` | ทดสอบ API จริง — อัปโหลดภาพ ดูข้อความ/JSON/เวลา, คัดลอกคำสั่ง curl, ดาวน์โหลดผล |
| `/status` | สถานะระบบ (version, uptime, โมเดล, watch folder, งานล่าสุด) รีเฟรชเองทุก 3 วินาที |

ทุกหน้าใช้ปุ่ม **EN / ไทย** ร่วมกัน (จำภาษาเดียวกัน)

## 5.2 เปิดแบบไหน (จำค่าได้)

หน้าแรกมีช่อง **เมื่อเริ่มโปรแกรม** เลือกได้ 3 แบบ (มีผลตั้งแต่เปิดครั้งถัดไป)

| แบบ | คำสั่งเทียบเท่า | ลักษณะ |
|---|---|---|
| เปิดหน้าต่างโปรแกรม (GUI) | `--window` | หน้าต่างจริงบนเดสก์ท็อป (WebView2) — ไม่ต้องมีเบราว์เซอร์ |
| เปิดเบราว์เซอร์ | `--browser` | เปิดแท็บเบราว์เซอร์ปกติ (ค่าเริ่มต้น) |
| ไม่เปิดอะไร (headless) | `--no-browser` | ทำงานเงียบ ๆ เปิดเองเมื่อพร้อม |

- ค่าที่เลือกบันทึกที่ `settings.json` ข้างโปรแกรม และ
  `%LOCALAPPDATA%\OpenThai2OCR\settings.json` (ใช้ร่วมกันทุกที่วาง exe)
- คำสั่งบน Command line ชนะค่าที่จำไว้เสมอ
- โหมดหน้าต่างต้องมี `pywebview` (มีใน exe แล้ว / รันจากซอร์ส: `pip install pywebview`)
- ตั้งใจใช้แบบไม่มีหน้าจอ + watch folder:
  `OpenThai2OCR.exe --no-browser --watch "D:\inbox" --watch-out "D:\outbox"`

## 5.3 ขนาดตัวอักษร (ทุกหน้า)

- ปุ่ม `A−` / `A` / `A+` มีทุกหน้า (OCR / สอนใช้ API / ทดสอบ API / สถานะ) และใช้ค่าเดียวกัน
  (จำใน `localStorage` ของเบราว์เซอร์ ค่า `ocrFontScale`)

## 6. ใช้งานผ่านโปรแกรมอื่น (API)

เปิดโปรแกรมค้างไว้ แล้วเรียก

```bash
curl -F "file=@page.png" "http://127.0.0.1:5000/api/ocr"
```

ดูตัวอย่าง PHP / Python / JavaScript / C# และรายละเอียดฟิลด์ → [API.md](API.md)

## 7. แก้ปัญหาที่พบบ่อย

| ปัญหา | สาเหตุ/วิธีแก้ |
|---|---|
| เปิด exe แล้วเบราว์เซอร์ไม่ขึ้น | เปิด `http://127.0.0.1:5000` เอง · ถ้าพอร์ตชน ให้รัน `--port 8080` |
| "Windows protected your PC" | ไฟล์ exe ไม่ได้เซ็นชื่อ — กด More info → Run anyway |
| ขึ้น "ไม่พบไฟล์โมเดล" | ใช้ build แบบ onedir ต้องมีโฟลเดอร์ `models` ข้าง exe (onefile ฝังในตัวแล้ว) |
| เครื่องอื่นเรียก API ไม่ได้ | รันด้วย `--host 0.0.0.0` + เปิด Firewall ขาเข้าพอร์ตนั้น |
| เปิดโปรแกรมช้า | onefile ต้องแตกไฟล์ลง temp ทุกครั้ง (~2–3 วินาที) · ใช้ build แบบ onedir จะเปิดเร็วกว่า (~1 วินาที) |
| อ่านช้ามาก | ลดความละเอียด/`det.limit` · ปิดโปรแกรมอื่นที่กิน CPU |
| ลายมืออ่านไม่ขึ้น | โมเดลนี้ออกแบบสำหรับตัวพิมพ์ — ลายมือต้องใช้โมเดล VLM อื่น |
| ภาษาไทยเพี้ยนในโปรแกรมอื่น | ตรวจว่าโปรแกรมปลายทางอ่าน response เป็น UTF-8 |
| โหมดหน้าต่าง: กด `.txt/.docx/.pdf/.csv/.json` แล้วไม่มีอะไร | มีหน้าต่าง **บันทึกไฟล์ของ Windows** ขึ้นให้เลือกที่เก็บ (WebView2) — ถ้าไม่เห็น ให้กดที่หน้าต่างโปรแกรมก่อนแล้วลองใหม่ |
| คัดลอกแล้วไม่ได้ | ใช้ปุ่มคัดลอกอีกครั้งในหน้าต่างโปรแกรม (ต้องโฟกัสหน้าต่าง) |

## 8. โครงสร้างโปรเจกต์

```
app.py                  เซิร์ฟเวอร์ Flask + API + ตัวจัดการภาพ
templates/index.html    หน้าเว็บ (ธีมขาว, paste, หลายไฟล์, สเกลฟอนต์)
models/                 โมเดล ONNX + runtime (line_engine.py, thai_norm.py)
models/runtime/         ตัวอ่านหน้า (LineOCR) จาก Hugging Face
docs/                   คู่มือ, API, build
tools/                  สคริปต์ช่วยเหลือ (ดาวน์โหลดโมเดล, release notes, smoke test, exe_smoke)
run_web.bat             รันจากซอร์ส (Windows)
build_exe.bat           build exe ไฟล์เดียว (Windows)
build_exe_onedir.bat    build แบบโฟลเดอร์ (Windows)
OpenThai2OCR.spec       สเปก PyInstaller แบบ onefile
OpenThai2OCR_onedir.spec  สเปก PyInstaller แบบ onedir
```
